# ERA EVENT — GitHub Pages

Готовий статичний сайт для `https://eraevent.eu`.

## Публікація

1. Завантажте **вміст цієї папки** в корінь GitHub-репозиторію.
2. У GitHub відкрийте `Settings → Pages`.
3. У `Build and deployment` виберіть `Deploy from a branch`.
4. Виберіть гілку `main` і папку `/(root)`, потім натисніть `Save`.
5. У полі `Custom domain` вкажіть `eraevent.eu`.

Файл `CNAME` уже доданий.

## Мови

Сайт підтримує українську, польську, російську та англійську мови.

## Редактор медіатеки

У самому низу головної сторінки натисніть `Адмінпанель` і введіть встановлений
пароль. У редакторі можна:

- перетягувати фотографії та змінювати їхній порядок;
- рухати кадр вліво, вправо, вгору та вниз;
- змінювати масштаб кожної фотографії.

Після редагування натисніть кнопку завантаження. Новий файл
`gallery-settings.json` потрібно завантажити в корінь GitHub-репозиторію
замість попередньої версії.

Це статичний сайт: редактор не має доступу до GitHub і не може самостійно
опублікувати зміни.
